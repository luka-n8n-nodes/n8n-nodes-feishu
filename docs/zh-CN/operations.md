# 操作参考

[English](../en/operations.md) · [首页](../../README.md) · [入门](./getting-started.md) · [进阶](./advanced.md)

在「飞书」节点中先选 **Resource（资源）**，再选 **Operation（操作）**。下表保留界面中的操作原名，共 11 类资源、147 项操作；两个触发器和响应节点不计入此数。

**如何读表：** `✓` 表示提供 Return All 开关（共 26 项，默认关闭）；`—` 表示没有该开关，不代表操作只处理一条数据。开启 Return All 后，自动翻页获取当前权限和筛选条件下的全部结果。标为“增强”或“封装”的操作可能组合多个接口。详见[分页](./advanced.md#pagination)与[多维表格增强操作](./advanced.md#bitable)。

**凭证限制：**「搜索用户」「搜索云文档」仅支持用户级别凭证。其他操作仍需按对应接口确认可用身份、权限范围与资源授权；未标注不代表两种凭证都可用。两个触发器只使用应用凭证，详见[凭证选择](./getting-started.md#credentials)。
